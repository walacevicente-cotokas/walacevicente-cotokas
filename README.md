## ⭐ Featured engineering case

### [REP-Monitor — Enterprise Fleet Monitoring](https://github.com/walacevicente-cotokas/rep-monitor-case-study)

A documented case study of a field-oriented monitoring platform connecting a Flutter mobile app, Next.js web portal, FastAPI services, PostgreSQL and external enterprise data sources.

**What it demonstrates**
- **Software delivery:** multi-client workflows, authentication, API integration and operational interfaces
- **Backend & data:** inventory reconciliation, monitoring-status modeling, SQL and scheduled data processing
- **Cloud & infrastructure:** Google Cloud Run deployments, enterprise connectivity and Windows automation
- **Engineering judgment:** performance trade-offs, security boundaries, import review, documentation and testing
